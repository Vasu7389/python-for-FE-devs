# Help a frontend developer learn Python

Small improvements are welcome: clearer wording, a better JavaScript comparison, a reproducible bug report, or an example that runs more clearly.

Before opening a pull request:

1. Read the linked lesson and run the example.
2. Keep the change focused on one idea.
3. Use simple English, descriptive names, and expected output.
4. Explain any new Python syntax before using it in an exercise.
5. Share what you ran and what output you saw in the pull request description.

For a new lesson idea, open an issue first so we can fit it into the roadmap. Do not include passwords, tokens, personal information, proprietary code, or private course assets in issues or pull requests.

No test suites or publishing infrastructure are hosted in this public repository. Maintainers handle those privately. You can report a failing case with a short input/output example.

Be patient and respectful. Confusion is useful feedback, and questions are welcome.
