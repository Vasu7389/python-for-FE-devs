# Python for Frontend Devs — Roadmap

This is the planned sequence. Lesson 1 is available; later lessons are in progress, not a complete course yet.

[Start on Codinn](https://www.codinn.dev/courses/python-for-frontend-devs)

The planned capstone is a team task app. Modules combine learning, exercises, debugging, and optional interview practice.

## Module 1 · Python mental models

- Python truthiness versus JavaScript
- Names, mutability, and identity
- Functions, arguments, and safe defaults

## Module 2 · Python application foundations

- Collections, comprehensions, and iteration
- Exceptions and context managers
- Modules, virtual environments, and dependencies

## Module 3 · Typed and tested Python

- Type hints and runtime boundaries
- Dataclasses and domain models
- Testing a typed task CLI

## Module 4 · HTTP and first API

- HTTP contracts for frontend developers
- Your first FastAPI endpoint
- Request validation with Pydantic

## Module 5 · API structure

- Dependency injection and configuration
- Errors and API contracts
- Filtering, sorting, and pagination

## Module 6 · Async and frontend integration

- Async IO and blocking operations
- React integration and generated contracts
- API integration testing

## Module 7 · Relational foundations

- Transactions and concurrency

## Module 8 · Persistence layer

- SQLAlchemy sessions and boundaries
- Alembic migrations and rollout
- Repository and service tradeoffs

- Connection pools and load experiments

## Module 10 · Identity

- Authentication integration tests

## Module 12 · Application security
